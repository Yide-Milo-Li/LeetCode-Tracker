# Development scripts

Users must provide their own compatible database and have the rights to use its contents. This repository does not include a problem dataset. A supported database import command and user-facing importer are planned, not implemented.

Run `npm run docs:check` from the repository root with Node.js 24. It checks maintained Markdown titles and local links, exits nonzero on failure, and does not modify files. Application startup, packaging and data import are not supported public commands yet.
