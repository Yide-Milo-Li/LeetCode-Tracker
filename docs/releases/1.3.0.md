# Release 1.3.0 — Guided onboarding, local recommendations, and Windows/macOS parity

Release 1.3.0 brings a guided three-step first-run setup, reorganized four-tab Settings, the `phase39-v1` local recommendation engine (SQLite schema v12 and portable Snapshot Bundle v5), searchable and recency-ordered Topic Insights, local and guarded AI note formatting, palette-tinted native app icons, and aligned Windows 11 x64 and Apple Silicon macOS 14+ desktop distributions.

## Download and install

Download the installer for your platform and `SHA256SUMS.txt` from [Release 1.3.0](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.3.0). Both packages bundle the React UI, Fastify API, SQLite storage engine, and a private Node.js 26.13.0 runtime — **no Node.js, npm, Git, or Rust installation is required**.

| Platform | Download asset | First-launch note |
| --- | --- | --- |
| **Windows 11 x64** | `LeetCode-Tracker_1.3.0_x64-setup.exe` | Per-user NSIS installer (no admin rights required). Because the installer is unsigned, if Windows SmartScreen appears, click **More info → Run anyway**. |
| **macOS 14+ (Apple Silicon)** | `LeetCode-Tracker_1.3.0_aarch64.dmg` | Open the `.dmg` and drag **LeetCode Tracker.app** into **Applications**. Because the bundle is ad-hoc signed and unnotarized, if Gatekeeper blocks the first open, go to **System Settings → Privacy & Security → Open Anyway** (or right-click **LeetCode Tracker.app → Open**; if quarantine persists, run `xattr -cr "/Applications/LeetCode Tracker.app"`). |
| **Checksums** | `SHA256SUMS.txt` | Verify with `Get-FileHash <file> -Algorithm SHA256` on Windows or `shasum -a 256 <file>` on macOS. |

## What changed since 1.2.0

- **Three-step first-run setup & four-tab Settings**:
  - New installations open a guided setup on **Today**: confirm your **Timezone** (with language and light/dark/system mode switches), import your **JSONL problem catalog**, and pick a **Study rhythm** (a recommended weekday 3-problem preset or custom schedule). Every step can be revisited or skipped.
  - **Settings** is organized into four focused tabs: **General** (language, timezone, swap/removal feedback prompt toggle, notes format-on-save toggle), **Appearance** (interface mode and 10 palettes), **AI assistant** (provider, API key, and collapsible **Advanced: model and endpoint**), and **Data** (one-file cross-device migration and Obsidian/Notion exports).
- **Local recommendation engine, outcome review v2, and token usage accounting (`phase39-v1`, SQLite v12, Bundle v5)**:
  - Routine bilingual plan explanations and encouragement are generated 100% locally. Optional AI calls are bounded to unresolved semantic preferences across tied open slots (at most 30 candidates) and record model provenance only when the validated result changes selection.
  - Strategies and temporary overrides offer opt-in `outcome-v2` review intervals (1/3/7/14/30-day ladder driven by independent/assisted/unsolved feedback), opt-in personal duration calibration, and an optional daily time budget with infeasibility notices.
  - Swapping or removing a Today problem optionally records a reason (`time_unavailable`, `already_familiar`, `topic_mismatch`, `too_difficult`, `other`) without fabricating practice history.
  - Profile-local diagnostics (`diagnostics/llm-usage.jsonl`, capped at 30 days / 5 MiB) track provider token usage and selection effect without storing keys, prompts, notes, or titles.
- **Reorganized Progress Statistics & searchable Topic Insights**:
  - **Progress → Statistics** highlights outcome KPIs (Unique Solved, Solved This Week, Current Streak, and Due Today / Overdue reviews), the 365-day activity heatmap, difficulty mastery meters, topics worth attention, and a sortable **Topic Insights** table with instant topic search, recency-first ordering, and expandable 30-day evidence rows.
- **Notes formatting & bilingual UX polish**:
  - **Notes** adds local Markdown format-on-save (enabled by default, with one-click **Undo format** after saving) verified by a worker so code blocks, inline code, math, and text remain intact.
  - An optional **AI format** action proposes structural layout improvements for the whole note or a selected text range while withholding code blocks, formulas, and links from provider text; review the diff before applying to your draft.
- **Palette-tinted native app icons & Windows ↔ macOS behavioral alignment**:
  - Switching palettes or light/dark mode dynamically tints the favicon, the macOS Dock icon, and Windows `ICON_SMALL` (titlebar) / `ICON_BIG` (taskbar and Alt+Tab) icons rasterized directly at OS target DPI dimensions.
  - Fixed the **Settings → Data** migration restore confirmation dialog so importing Snapshot Bundle v3 and v5 files displays the full migration summary (`Complete migration · v1.3.0 · ...`) rather than the legacy v1 partial-restore notice.
  - Aligned native icon PNG/variant validation across macOS and Windows, added platform-aware Notes shortcuts (`⌘S` / `Ctrl+S` and `⌘\` / `Ctrl+\`) to the `?` Keyboard Shortcuts modal, guarded hidden Notes workspace shortcuts when on other views, and unified `--port` / `PORT` / `.env` resolution across Windows (`start-desktop.ps1`, `start.bat`) and macOS (`start-desktop.sh`, `start-desktop.ts`) source-mode launchers.
- **Expanded AI model & reasoning effort support**:
  - Supports **Google Gemini** (`models/gemini-3.8-flash`, `models/gemini-4-hydrogen` via `thinkingConfig.thinkingLevel`), **OpenAI** (`gpt-6-luna`, `gpt-6.1-terra` via `reasoning_effort`), and **DeepSeek** (`deepseek-flash` via `reasoning_effort` and `thinking`), reserving reasoning token budgets on capped requests.

## Upgrade and cross-device migration

- **Upgrading an existing installation**: Quit the running app (`Cmd+Q` on macOS or close the window on Windows) before installing 1.3.0. Your local database (`%LOCALAPPDATA%\com.leetcodetracker.desktop\tracker.sqlite` on Windows or `~/Library/Application Support/com.leetcodetracker.desktop/tracker.sqlite` on macOS) automatically creates a verified pre-migration backup in `backups/` before upgrading older schemas (v3–v10) to schema v12.
- **Moving between Windows and macOS**: Open **Settings → Data → Export migration file** on your source computer to save a Snapshot Bundle v5 `.json` file, copy it to the target computer, and choose **Settings → Data → Import migration file**. Provider API keys are excluded from bundles and preserved on the target device.
