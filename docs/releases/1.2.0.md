# Release 1.2.0 — Built-in practice timer and title links

This release adds a built-in single-problem practice timer linked to practice records, and makes Today problem titles link directly to the original problem while removing the redundant open-icon button. Download `LeetCode-Tracker_1.2.0_x64-setup.exe` and `SHA256SUMS.txt` from [Release 1.2.0](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.2.0).

## Added and improved

- **Built-in practice timer**: Each Today row and Problems catalog row offers a start/stop timer button. Only one timer runs at a time; starting another problem switches the timer and discards the previous run. The active timer survives view switches and page reloads, and a status pill shows the running clock with stop and discard actions. Stopping never creates a record: it keeps whole minutes (rounded up, minimum 1) pending for that problem. Clicking the completion circle stops the same-problem timer and pre-fills the enrich dialog; manual editors pre-fill pending minutes when empty and offer stop-and-fill while the timer runs. Saving clears the pending minutes.
- **Today titles link to the problem**: The problem title on Today rows is now the external link (new tab), replacing the standalone open-icon button and leaving six row actions. Invalid URLs keep plain text.

## Upgrade and data

Close the running app, then install 1.2.0. Keep the existing application data directory. This release changes frontend interaction flows and application version metadata; it introduces no database schema migration. Existing SQLite data and Snapshot Bundles remain fully compatible.

## Verification and limits

All 427 JavaScript/Web/sidecar tests (including 141 Web DOM tests covering the timer, title links, notes workspace and planning components) and 7 Rust tests pass. The web bundle compiles cleanly with Vite.
