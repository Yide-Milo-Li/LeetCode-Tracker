# Release 1.1.0 — Desktop workspaces and adaptive practice

Download **LeetCode-Tracker_1.1.0_x64-setup.exe** and **SHA256SUMS.txt** from [Release 1.1.0](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.1.0). The installer bundles the private Node.js 24.15.0 runtime; users do not need developer tools.

## What changed since 1.0.1

- Redesigned Today combines daily completion, plan actions, and seven-day activity. Add one works locally without model calls; removal updates the plan and asks for confirmation before revoking associated completion records.
- Problems adds compact filters and a refreshed catalog table. Progress opens Statistics first, with updated topic insights and a separate Records tab.
- Notes adds a formatting toolbar, lightweight Markdown preview, Edit / Split / Preview modes, focus mode, a collapsible timeline, and a Copy menu for Obsidian/Notion. Save/discard/cancel protects unsaved edits when switching problems.
- Knowledge profiles distinguish self-reported outcome feedback, duration evidence, developing topics, and unknown data. Adaptive planning preserves hard quotas and eligibility constraints.
- Partial review uses a fixed integer count. Equivalent rule changes preserve the plan; difficulty inputs support short-circuit auto-fill.
- SQLite schema v10 and Snapshot Bundle v3 preserve nullable practice outcomes. Imports remain compatible with v1/v2; provider keys are excluded and existing target keys are preserved.
- Apple Silicon macOS 14+ build configuration and native migration CI are included for internal use. This public release distributes Windows x64 only.
- README, user/developer documentation, architecture labels, and all eight showcase screenshots reflect this version. Screenshots contain fictional synthetic data.

## Upgrade and data

Close the application before installing. Back up your populated profile first and keep it private: raw SQLite backups may contain provider keys. Supported older schemas migrate to v10 with migration backup protection. Do not replace your profile with demo data or delete WAL/lock files to work around startup issues. Snapshot v3 is the current portable migration format; do not assume an older application can open a v10 database. Full populated-profile installer upgrade/downgrade acceptance remains pending.
