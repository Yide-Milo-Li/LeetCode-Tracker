# Release 1.1.1 — Warning icon alignment and feedback UI polish

This patch fixes the warning alert icon vertical misalignment and improves Today plan scheduling notice presentation. Download `LeetCode-Tracker_1.1.1_x64-setup.exe` and `SHA256SUMS.txt` from [Release 1.1.1](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.1.1).

## Fixed

- **Warning and feedback icon misalignment**: Fixed an issue where alert and feedback icons appeared misaligned with text content. Explicit line-height (`1.6`) has been declared on `.feedback` and `.alert` containers, and child lists (`ul`, `ol`) and paragraphs (`p`) have their default browser margins reset to zero so text lines align cleanly with the 16px alert icon.
- **Today plan notice rendering**: When a plan generates a single scheduling notice (such as fallback coverage notices), the notice is now rendered directly as plain banner text rather than being wrapped in an unnecessary single-item unordered bulleted list with large indents. Multiple notices retain structured list presentation.

## Upgrade and data

Close the running app, then install 1.1.1. Keep the existing application data directory. This patch changes UI layout styles and application version metadata; it introduces no database schema migration. Existing SQLite data and Snapshot Bundles remain fully compatible.

## Verification and limits

All 418 JavaScript/Web/sidecar tests and TypeScript checks pass. The web bundle compiles cleanly with Vite.
