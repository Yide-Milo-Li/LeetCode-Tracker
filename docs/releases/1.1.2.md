# Release 1.1.2 — Today note menu, copy dropdown alignment, and UI centering polish

This release improves the Today practice row note interaction with a dual-action menu, fixes dropdown clipping for quick copy buttons inside drawers, resolves a note-switching deadlock when jumping to the workspace, and centers tags in prompt override modals and Today problem cards. Download `LeetCode-Tracker_1.1.2_x64-setup.exe` and `SHA256SUMS.txt` from [Release 1.1.2](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.1.2).

## Fixed and improved

- **Quick copy dropdown clipping**: Configured `QuickCopyButtons` with an alignment prop (`align="left" | "right"`). In the quick note slide drawer it opens cleanly toward the right without being clipped by the drawer viewport edges, while in the notes workspace header it continues right-aligning cleanly.
- **Today note button and quick actions**: Renamed the Today problem note button to "Note" / "笔记" with a convenient dropdown offering two workflows: "Go to workspace" / "去工作区写新笔记" (smoothly navigates to the Notes workspace with the selected problem preselected) and "Quick view past notes" / "速查过往笔记" (opens the slide-out drawer for quick reference without leaving the Today plan).
- **Notes workspace navigation deadlock**: Fixed a bug where jumping from the drawer to the notes workspace prevented subsequent note switching. Decoupled initial selection state from the workspace's active note selection via `onClearInitialFrontendId`, and added fallback single-problem summary fetching for problems not currently on the paginated notes list.
- **Card and tag vertical alignment**: Centered "Changed fields" / "变更字段" tags inside the prompt override modal (`.changed-tags-row`) and vertically aligned Today problem items, completion circles, and action button groups (`.today-problem`, `.problem-actions`, `.completion-circle`).

## Upgrade and data

Close the running app, then install 1.1.2. Keep the existing application data directory. This patch changes UI layout styles, interaction flows, and application version metadata; it introduces no database schema migration. Existing SQLite data and Snapshot Bundles remain fully compatible.
