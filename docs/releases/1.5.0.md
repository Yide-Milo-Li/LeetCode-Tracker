# LeetCode Tracker 1.5.0

- **Ordered goal lists.** Add problems from your catalog or paste their IDs in practice order. Switch goals on Today, reorder entries, and add a selection to several lists while preserving their existing order and checkmarks.
- **Favorites.** Star problems from Today or Problems and organize them in one or more folders. The Favorites workspace lets you browse by folder and work with a selection across pages. Removing a folder keeps its problems in All favorites.
- **Today and practice.** See daily plan progress, goal progress, and a seven-day activity chart with links to the records for each day. Completing a problem shared by the strategy and a goal list uses one practice record. Correcting or revoking that record updates the linked checkmark if no other qualifying record remains.
- **Review settings.** Set a cap per strategy and choose review spacing under **Settings → Practice & notes**. A due review can use available review capacity before the plan fills the remaining slots with new problems.
- **MCP and sync.** Local AI clients can manage favorite folders, change goal memberships, and page through ordered goal entries. Local practice edits can continue while a device snapshot uploads.

Use **Settings → General → App updates** on an official 1.4.0 or 1.4.1 desktop build. Users on 1.3.1 or earlier can quit Tracker and install the package for their platform.
