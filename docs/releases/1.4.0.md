# 1.4.0 release notes

LeetCode Tracker 1.4.0 adds device sync, MCP client access and signed in-app updates for Windows x64 and Apple Silicon macOS. [Download 1.4.0](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.4.0)

## What changes for users

- **Switch computers.** Publish a snapshot to a sync folder or authorize Google Drive from the app. On the receiving computer, preview the snapshot before replacing local data. If two devices have edits, choose which version to keep. The app takes a local safety backup. Direct Drive sync can resume larger uploads and retrieve small consecutive changes in one check. [Device sync guide](../sync.md)
- **Use a local AI client.** The bundled MCP server lets a client read today's plan, log practice, edit notes and manage study strategies. Reads work while the desktop app is open. To allow writes during that session, enable **Settings → AI clients → Allow AI client writes** on that device. The optional LCT skill adds shortcuts for common tasks. [Client setup and tool reference](../../apps/mcp/README.md)
- **Find preferences by task.** Practice feedback and note formatting share the **Practice & notes** tab. Provider credentials belong under **AI assistant**, MCP setup under **AI clients** in the desktop app, and migration files under **Data**. [Desktop workflow](../desktop-workflow.md)
- **Check for desktop updates.** The official Windows x64 and Apple Silicon macOS builds check for newer stable releases. The app verifies the downloaded update's signature before offering **Install and restart**. [Desktop update guide](../desktop.md#14-app-updates)
- **Load recent activity and import progress.** Today reads its seven-day overview separately from full statistics. AI-assisted progress import can refer to source lines, and truncated output prompts you to submit fewer rows. Migration file import also accepts a saved Today plan whose final item was removed.

## Upgrading from 1.3.1

Quit 1.3.1 and run the Windows installer or replace the app in macOS Applications. This first upgrade is manual. Existing profiles use the same data directory, SQLite schema v12 and Snapshot Bundle v5. A same-device upgrade needs no export or reimport. The existing local API stays under `/api/v1`. The bundled MCP server reports version `1.4.0`.

Windows Authenticode signing and macOS notarization remain outstanding. The update signature verifies packages downloaded through the app. Platform first-launch guidance and checksum instructions are in the [installation guide](../desktop.md).

## Release verification

Verify the installer against `SHA256SUMS.txt` from the release. The release workflow checks both updater package signatures before staging the downloads. [Verification and limitations](../status.md) · [CI runs](https://github.com/Yide-Milo-Li/LeetCode-Tracker/actions/workflows/ci.yml)
