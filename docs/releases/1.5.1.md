# LeetCode Tracker 1.5.1

- **Problems.** Open the catalog, Favorites or Goal lists from one sidebar entry. Search and sort goal lists and large favorite libraries. The folder and goal pickers keep your selections as you filter or change pages. **Use on Today** makes a goal list your active checklist.
- **Notes.** Sort by last solved or last note update, and switch between ascending and descending order. Group problems by goal list or favorite folder. Format Markdown from the editor toolbar or keyboard, and undo or redo edits.
- **Practice.** Checking a goal-only problem on Today saves a practice record and offers optional duration, outcome and notes. If an imported Accepted submission already completed the same problem in today's strategy, the goal check reuses it. Revoking the import reopens both entries when it was the only qualifying evidence.

- **Performance.** The setup guide loads on demand, catalog and note searches cancel stale requests, and statistics reuse recent calculations. Routine edits share a verified background backup, while bulk imports and upgrades take a recovery snapshot before writing.

Use **Settings → General → App updates** on official desktop builds from 1.4.0 onward. Upgrades keep the same profile location, SQLite schema v12 and Snapshot Bundle v5. [Desktop updates](../desktop.md#14-app-updates) · [Verification](../status.md)
