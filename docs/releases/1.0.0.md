# Release 1.0 — v1.0.0

Release date: 2026-09-14. Windows x64, unsigned NSIS installer.

## Install

Download `LeetCode-Tracker_1.0.0_x64-setup.exe` and `SHA256SUMS.txt` from [the release page](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.0.0). Run the installer, then launch the app from the Start Menu. No separately installed Node.js, npm, Git, or Rust is required. The installed application includes a private Node.js 24.15.0 runtime; the single installer expands into multiple application files.

Microsoft WebView2 is required. If absent, installation downloads its bootstrapper and needs a network connection. Windows 11 x64 is the primary target. The installer is not code-signed.

## Included

- Shared English/Chinese desktop interface, ten theme palettes, keyboard navigation, and 1024px+ desktop layouts.
- BYOD JSONL catalog preview/import, weekly strategies, local planning, practice history, progress analytics, and Markdown problem notes.
- Optional Gemini, OpenAI, and DeepSeek configuration; local code validates model suggestions and owns persistence.
- Native save dialogs for Markdown, Obsidian ZIP, Notion CSV, and portable snapshot bundles, with unique temporary files and atomic replacement.
- Parsed HTTPS external-link validation, direct Windows URL handling, authenticated loopback transport, and a private startup handshake.
- Bounded startup with retry, continuous pipe draining, graceful shutdown with a deadline, and Windows Job Object process ownership.
- Bundle exports exclude provider keys; bundle imports ignore incoming keys and preserve existing local credentials.

The release also upgrades `@fastify/static` to 10.1.3 in both dependency manifests. A route-guard bypass regression fails on the old dependency and passes after upgrading; the fresh npm audit reports zero known vulnerabilities.

## Verification

The release preparation passed 312 JavaScript/Web/sidecar tests (216 backend/platform, 95 Web DOM, one isolated bundled-server lifecycle test), six Rust tests, TypeScript checks, documentation links, Rust fmt/clippy, and a Windows production installer build. The isolated sidecar test uses the private Node executable and a temporary directory without repository dependencies.

These results are local and synthetic. Check [GitHub Actions](https://github.com/Yide-Milo-Li/LeetCode-Tracker/actions) for remote CI results; adding a workflow is not itself a passing run. The release attaches the installer and its SHA-256 checksum.

## Known limitations and data handling

- Complete clean-machine installation, overwrite upgrade/downgrade, Windows 10 compatibility, native save-dialog interaction, and the full WebView2 UI/lifecycle matrix remain unverified. Local packaging and DOM tests do not substitute for those checks.
- Full SQLite migration and custom data-directory selection are unfinished. The desktop app starts its own profile under `%LOCALAPPDATA%\com.leetcodetracker.desktop\`; it does not automatically import a source checkout's `.local` database. Portable bundles are not a complete SQLite migration mechanism.
- Keys are stored in local SQLite without OS credential encryption. Raw database backups may contain keys. Keep them private.
- Optional AI sends relevant problem metadata, instructions, or progress text to the configured provider/gateway. Progress formatting requires a working provider. Live-provider availability was not tested for this release.
- Cold-start/query performance targets are not verified. No fixed latency guarantee is made.
- No automatic updater, native macOS/Linux/ARM64 package, or mobile UI support is included.
