# LeetCode Tracker 1.4.1

- A pinned macOS Dock icon keeps its selected palette after the app quits, including the first quit after a fresh install. Choosing the default palette in Light mode restores the shipped icon.
- Automatic device sync uses a quota-aware schedule for configured sync targets. Settings improves folder selection and reports sync results. [Device sync guide](../sync.md)
- LeetCode progress imports resolve relative time labels against the capture time and timezone.

On 1.4.0, open **Settings → General → App updates** to install this update. Users on 1.3.1 or earlier can quit Tracker and install the package for their platform. Existing profiles use the same data directory, SQLite schema v12 and Snapshot Bundle v5. [Desktop update and installation guide](../desktop.md)

The Windows x64 installer and Apple Silicon macOS DMG are available from the GitHub Release with SHA-256 checksums. The release workflow verifies both in-app update signatures before staging downloads. [Verification](../status.md)
