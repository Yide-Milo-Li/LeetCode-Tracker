# Release 1.3.1 — Provider-neutral hints, palette-aware styling, and native popover menus

Release 1.3.1 is a frontend patch on 1.3.0. It names the configured AI provider in import hints, simplifies the review spacing picker, makes the heatmap and several controls follow the active palette, moves Today and Notes menus onto native popovers, and restructures the web client into smaller modules. Storage, API, and native host behavior are unchanged.

## Download and install

Download the installer for your platform and `SHA256SUMS.txt` from [Release 1.3.1](https://github.com/Yide-Milo-Li/LeetCode-Tracker/releases/tag/v1.3.1). Both packages bundle the React UI, Fastify API, SQLite storage engine, and a private Node.js 26.13.0 runtime — **no Node.js, npm, Git, or Rust installation is required**.

| **Windows 11 x64** | `LeetCode-Tracker_1.3.1_x64-setup.exe` | Per-user NSIS installer (no admin rights required). Because the installer is unsigned, if Windows SmartScreen appears, click **More info → Run anyway**. |

## Fixed and improved

- **Provider-neutral import hint**: The **Progress → Import** hint names the AI provider configured in Settings (Gemini, OpenAI, or DeepSeek) instead of always naming Gemini.
- **Plain review spacing names**: Review spacing options in strategies and temporary overrides show plain strategy names without internal version ids, plus a one-line description of the selected option.
- **Palette-aware styling**: The yearly activity heatmap, select chevrons, tooltips, dialog scrims, and Notes difficulty badges now derive their colors from the active palette, so dark palettes such as Dracula no longer show the default green heatmap. Two previously undefined CSS tokens are now defined.
- **Native popover menus**: The Today **Note** menu and the quick-copy dropdowns open as native popovers (`popover="auto"`), which close on outside click or `Esc` and are no longer clipped by drawers. A manual fallback is kept for environments without the Popover API.
- **Quick-note drawer focus handling**: The quick-note drawer renders through the shared dialog, so keyboard focus stays inside the drawer, the background is inert while it is open, and focus returns to the opening control on close.
- **Web client restructuring**: Settings and Notes are split into focused section components and hooks, the stylesheet is split into ordered partials with palette tokens, and shared hooks handle abortable data loading, preference state, and cached date formatting. These changes are internal and keep the same behavior.

## Upgrade and data

Quit the running app, then install 1.3.1 over 1.3.0. This patch introduces no database schema migration: SQLite schema v12 and Snapshot Bundle v5 are unchanged, and existing data and migration files remain fully compatible. Bundles exported by 1.3.1 report `v1.3.1` in the migration summary.
